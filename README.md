# Directory Structure

## English

### Root Directory
- **CMakeLists.txt**: Main CMake configuration file for the project.
- **Doxyfile**: Configuration file for generating documentation using Doxygen.
- **format.sh**: Shell script for formatting code.
- **tidy.sh**: Shell script for running code tidy checks.
- **README.md**: This file, providing an overview of the project.

### build/
- **cmake_install.cmake**: CMake installation script.
- **CMakeCache.txt**: Cache file generated by CMake to store build configuration.
- **compile_commands.json**: Compilation database for tools like clang-tidy.
- **CTestTestfile.cmake**: File used by CTest for running tests.
- **Makefile**: Makefile generated by CMake for building the project.
- **PWChat/**: Directory containing build artifacts for the PWChat target.
- **CMakeFiles/**: Internal files and directories used by CMake during the build process.

### include/
- Placeholder for header files used in the project.

### src/
- **main.cpp**: Entry point of the application.

### tests/
- **CMAKELists.txt**: CMake configuration file for the test suite.
- **test_main.cpp**: Main file for running tests.

### ui/
- Placeholder for user interface-related files.

## Polish

### Katalog główny
- **CMakeLists.txt**: Główny plik konfiguracyjny CMake dla projektu.
- **Doxyfile**: Plik konfiguracyjny do generowania dokumentacji za pomocą Doxygen.
- **format.sh**: Skrypt powłoki do formatowania kodu.
- **tidy.sh**: Skrypt powłoki do sprawdzania porządku w kodzie.
- **README.md**: Ten plik, zawierający przegląd projektu.

### build/
- **cmake_install.cmake**: Skrypt instalacyjny CMake.
- **CMakeCache.txt**: Plik pamięci podręcznej generowany przez CMake do przechowywania konfiguracji budowy.
- **compile_commands.json**: Baza danych kompilacji dla narzędzi takich jak clang-tidy.
- **CTestTestfile.cmake**: Plik używany przez CTest do uruchamiania testów.
- **Makefile**: Plik Makefile generowany przez CMake do budowy projektu.
- **PWChat/**: Katalog zawierający artefakty budowy dla celu PWChat.
- **CMakeFiles/**: Pliki i katalogi wewnętrzne używane przez CMake podczas procesu budowy.

### include/
- Miejsce na pliki nagłówkowe używane w projekcie.

### src/
- **main.cpp**: Punkt wejścia aplikacji.

### tests/
- **CMAKELists.txt**: Plik konfiguracyjny CMake dla zestawu testów.
- **test_main.cpp**: Główny plik do uruchamiania testów.

### ui/
- Miejsce na pliki związane z interfejsem użytkownika.
